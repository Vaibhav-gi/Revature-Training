EXCEPTIONS
 Exceptions – Basics
Q1 (Beginner): What is an exception?

Answer:
An exception is an abnormal condition that occurs during program execution and disrupts normal flow.

Example:

int a = 10 / 0; // ArithmeticException

Q2 (Beginner): Difference between Exception and Error?

Answer:

Exception	Error
Recoverable	Not recoverable
Occurs due to program logic	Occurs due to JVM/system
Example: IOException	Example: OutOfMemoryError
Q3 (Intermediate): Explain Exception hierarchy

Answer:

Throwable
 ├── Error
 └── Exception
      ├── Checked Exceptions
      └── RuntimeException

 Checked vs Unchecked Exceptions
Q4 (Beginner): What are checked exceptions?

Answer:
Checked at compile time, must be handled.

Example:

FileReader fr = new FileReader("a.txt"); // IOException

Q5 (Beginner): What are unchecked exceptions?

Answer:
Checked at runtime, not mandatory to handle.

Example:

int x = 10 / 0; // ArithmeticException

 Exception Handling
Q6 (Beginner): How do you handle exceptions?

Answer:
Using try-catch-finally.

try {
    int a = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero");
} finally {
    System.out.println("Always executed");
}

Q7 (Intermediate): Can we have multiple catch blocks?

Answer:
Yes, from child to parent order.

 Custom Exceptions
Q8 (Beginner): How to create custom exception?

Answer:

class InvalidAgeException extends Exception {
    InvalidAgeException(String msg) {
        super(msg);
    }
}


Usage:

if(age < 18) {
    throw new InvalidAgeException("Not eligible");
}

Deadlock & Livelock
Q24 (Intermediate): What is deadlock?

Answer:
Two threads waiting for each other forever.

Q25 (Intermediate): Livelock?

Answer:

Singleton Pattern
Q38 (Beginner): What is Singleton?

Answer:
Only one instance of class.

    private static Singleton obj = new Singleton();

    }
}
