PART 1: MySQL & SQL Fundamentals

 Database & SQL Basics
Q1. What is a Database?

Answer:
A database is an organized collection of data that can be easily accessed, managed, and updated.

Example:
A database storing user details: id, name, email, password

Q2. What is SQL?

Answer:
SQL (Structured Query Language) is used to create, read, update, and delete data in a relational database.

SELECT * FROM users;

Q3. What is Consistency in a Database?

Answer:
Consistency ensures that a database moves from one valid state to another after a transaction.

 RDBMS Concepts
Q4. What is RDBMS?

Answer:
RDBMS stores data in tables (rows & columns) and enforces relationships using keys.

Examples: MySQL, PostgreSQL, Oracle

Q5. What is a Schema?

Answer:
A schema is a logical container for database objects like tables and views.

CREATE SCHEMA company;

Q6. What is a Table Structure?

Answer:
A table consists of:

Columns (fields)

Rows (records)

CREATE TABLE employee (
  id INT,
  name VARCHAR(50),
  salary DECIMAL(10,2)
);

 Normalization & Data Modeling
Q8. What is Normalization?

Answer:
Normalization reduces data redundancy and improves data integrity.

Forms:
1NF, 2NF, 3NF

Q9. What is Multiplicity?

Answer:
Multiplicity defines relationships:

One-to-One

One-to-Many

Many-to-Many

Q10. What is ERD?

Answer:
Entity Relationship Diagram visually represents entities and relationships.

 Keys & Integrity
Q11. What is a Primary Key?

Answer:
A primary key uniquely identifies a record and cannot be NULL.

id INT PRIMARY KEY

Q12. What is a Composite Key?

Answer:
A key formed using multiple columns.

PRIMARY KEY (order_id, product_id)

Q13. Foreign Key?

Answer:
Ensures referential integrity between tables.

FOREIGN KEY (dept_id) REFERENCES department(id)

Q14. Unique vs Alternate vs Secondary Key
Key	          		Purpose
Unique			No duplicate values
Alternate	  	Candidate key not chosen as PK
Secondary	 	Used for searching

 Subqueries & Joins
Q22. What is a Subquery?

Answer:
A query inside another query.

SELECT * FROM emp WHERE salary >
(SELECT AVG(salary) FROM emp);

Answer:

}
