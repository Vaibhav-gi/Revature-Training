1. What is Collection in Java?

A Collection is a framework that provides classes and interfaces to store, retrieve, and manipulate groups of objects.

 Located in java.util package.

Why use Collections?

Dynamic size (unlike arrays)

Built-in methods (add, remove, search, sort)

Standard data structures (List, Set, Map, Queue)

2. Collection Framework Hierarchy

3. List Collection (Allows Duplicates, Maintains Order)
Example: ArrayList
import java.util.ArrayList;

public class ArrayListExample {
    public static void main(String[] args) {

        ArrayList<String> names = new ArrayList<>();

        names.add("Rohan");
        names.add("Amit");
        names.add("Rekha");
        names.add("Amit"); // duplicate allowed

        System.out.println(names);
        System.out.println("First element: " + names.get(0));

        names.remove("Amit");
        System.out.println("After removal: " + names);
    }
}


 Output:

[Rohan, Amit, Rekha, Amit]
First element: Rohan
After removal: [Rohan, Amit, Rekha]

4. Set Collection (No Duplicates)

Example: HashSet
import java.util.HashSet;

public class HashSetExample {
    public static void main(String[] args) {

        HashSet<Integer> numbers = new HashSet<>();

        numbers.add(10);
        numbers.add(20);
        numbers.add(10); // duplicate ignored
        numbers.add(30);

        System.out.println(numbers);
    }
}


 Output (order not guaranteed):

[20, 10, 30]

5. Map Collection (Key–Value Pair)
Example: HashMap
import java.util.HashMap;

public class HashMapExample {
    public static void main(String[] args) {

        HashMap<Integer, String> students = new HashMap<>();

        students.put(1, "Manish");
        students.put(2, "Krish");
        students.put(3, "Disha");

        System.out.println(students);
        System.out.println("Student with ID 2: " + students.get(2));
    }
}

 Output:

{1=Manishh, 2=Krish, 3=Disha}
Student with ID 2: Amit

6. Queue Collection (FIFO – First In First Out)
Example: PriorityQueue
import java.util.PriorityQueue;

public class QueueExample {
    public static void main(String[] args) {

        PriorityQueue<String> queue = new PriorityQueue<>();

        queue.add("Java");
        queue.add("Python");
        queue.add("C++");

        System.out.println(queue);
        System.out.println("Removed: " + queue.poll());
        System.out.println(queue);
    }
}

7. Iterating Collections
Using Enhanced For Loop
for(String name : names) {

}

Using Iterator
Iterator<String> itr = names.iterator();
while(itr.hasNext()) {
    System.out.println(itr.next());
}

8. When to Use What?
Requirement             			Use
Ordered, duplicates allowed	ArrayList
No duplicates				HashSet
Key-value data				HashMap
FIFO operations				Queue
