Reactive Programming
 Beginner Level
Q1. What is Reactive Programming?

Answer:
Reactive Programming is an asynchronous, non-blocking programming paradigm that focuses on data streams and propagation of change.

Example (Conceptual):

Flux<Integer> numbers = Flux.just(1, 2, 3);
numbers.subscribe(System.out::println);

Q2. What is the Reactive Manifesto?

Answer:
The Reactive Manifesto defines four principles:

Responsive

Resilient

Elastic

Message-driven

Q3. What are Reactive Streams?

Answer:
Reactive Streams is a standard specification for asynchronous stream processing with backpressure.

Core Interfaces:

Publisher

Subscriber

Subscription

Processor

 Intermediate Level
Q4. What is backpressure?

Answer:
Backpressure allows a subscriber to control the rate at which it receives data from a publisher.

Example:

Subscription subscription;
subscription.request(5); // request only 5 items

Q5. Reactive Programming vs Traditional Programming
Traditional	Reactive
Blocking	Non-blocking
Synchronous	Asynchronous
Thread-per-request	Event-driven

Q7. Difference between Mono and Flux?

Answer:

Mono → 0 or 1 element

Flux → 0 to N elements

Example:

Mono<String> mono = Mono.just("Hello");
Flux<Integer> flux = Flux.just(1, 2, 3);

 Intermediate
Q8. How does non-blocking work in reactive apps?

Answer:
Reactive apps use event loops instead of blocking threads, improving scalability.

 Networking & Java Socket Programming
 Beginner
Q11. What is Socket Programming?

Answer:
Socket programming enables communication between two machines over a network.

Q12. What is ServerSocket?

Answer:
ServerSocket listens for incoming client connections.

Example:

ServerSocket serverSocket = new ServerSocket(8080);
Socket socket = serverSocket.accept();

Q13. What is Socket?

Answer:
Socket is used by the client to connect to a server.

Socket socket = new Socket("localhost", 8080);

 Intermediate
